# 我的个人网站

一个**纯静态**的个人网站，包含四个板块：**简介、小说书架、程序作品、小游戏**。
不需要服务器和数据库，双击 `index.html` 就能在本地浏览，也能免费发布到网上（见文末）。

## 目录结构

```
personal-website/
├── index.html            首页（简介 + 各板块最新内容）
├── novels.html           书架（小说列表）
├── novel.html            阅读页（正文 + 章节目录 + 字号调节）
├── programs.html         程序作品页（提供下载）
├── games.html            游戏页（网页游戏可在线玩）
├── css/
│   └── style.css         全站样式（想改配色看这里开头的 :root）
├── js/
│   ├── data.js           ★ 所有内容都在这个文件里改
│   └── app.js            渲染逻辑（一般不用动）
└── assets/
    ├── programs/         放程序文件（.py / .zip / .exe …）
    └── games/            放游戏（HTML5 游戏文件或 zip 压缩包）
```

## 本地预览

直接双击 `index.html` 用浏览器打开即可，无需安装任何东西。

## 怎么改内容（全部在 `js/data.js`）

用记事本或任意编辑器打开 `js/data.js`，照着里面的示例和注释改就行。

### 1. 改名字和简介

改 `profile` 里的 `name`、`tagline`、`bio`（自我介绍数组）、`skills`（标签）、`contacts`（联系方式）。

想放头像：把图片（如 `avatar.jpg`）放进 `assets/` 文件夹，然后把 `avatar: ""` 改成 `avatar: "assets/avatar.jpg"`。

### 2. 上传小说

在 `novels` 数组里复制一份示例条目，改标题、简介、日期，把每章正文粘贴到 `content` 里。

- 正文里的**空一行 = 分一段**（网页阅读页会自动分段并首行缩进）。
- ⚠️ 正文内容写在反引号 `` ` `` 之间，所以正文里**不要出现反引号**和 `${` 这两个符号。
- 修改后刷新浏览器即可看到新书出现在书架和首页。

### 3. 上传程序

1. 把程序文件放进 `assets/programs/`（多个文件建议打成一个 zip）。
2. 在 `programs` 数组里加一条记录，把 `file` 写成 `"assets/programs/你的文件名"`，页面上就会出现下载按钮。
3. 如果程序有在线演示页面（GitHub 仓库、博客文章等），把地址填到 `link`。

### 4. 上传游戏

分两种情况（都在 `games` 数组里加记录）：

- **网页游戏（HTML5）**：把游戏的主 HTML 文件（及其资源）放进 `assets/games/`，
  条目写 `type: "embed"`，`file` 指向入口 HTML。访客可以**直接在网站里玩**（弹窗嵌入），也可以新窗口打开。
- **打包好的游戏（exe / apk / zip）**：文件放进 `assets/games/`，
  条目写 `type: "download"`，`file` 指向该文件，页面上会出现下载按钮。

### 5. 换配色 / 字体

打开 `css/style.css`，最顶部 `:root` 里的变量就是全站配色，改几个色值整站换肤。

## 免费发布上线

### 方法一：GitHub Pages（推荐，完全免费）

1. 注册 [GitHub](https://github.com) 账号。
2. 新建一个仓库，名字必须是 `你的用户名.github.io`（例如用户名叫 `tom`，仓库就叫 `tom.github.io`）。
3. 把本文件夹里的**所有文件**上传到仓库（网页端拖拽上传即可）。
4. 稍等一两分钟，访问 `https://你的用户名.github.io` 就能看到你的网站，把这个网址发给朋友即可。

以后每次更新内容：改好 `data.js`、传好文件，再上传到 GitHub 覆盖，网站自动更新。

### 方法二：Vercel / Netlify（更省事）

- [Vercel](https://vercel.com) 或 [Netlify](https://netlify.com) 注册后，直接把整个文件夹拖进网页，几秒钟部署完成，会送你一个 `xxx.vercel.app` / `xxx.netlify.app` 网址。

### 绑定自己的域名（可选）

GitHub Pages / Vercel 都支持在设置里绑定自定义域名（域名需自行购买，一年几十元）。

## 常见问题

- **静态站没有"上传按钮"**：添加内容 = 文件放进 `assets/` + 在 `data.js` 里加一条记录，README 上面已写清楚。
- **想要评论、点赞、访问统计、后台管理上传**：这些需要后端或第三方服务，可以在这个网站基础上继续扩展（比如加 Disqus 评论、不蒜子统计，或改造成带后台的动态站）。
- **手机上看起来怎么样**：全站响应式设计，手机、平板、电脑都适配好了。
